| Aspect             | Scientist                                                            | Engineer                                                                 |
| ------------------ | -------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Main Goal          | Discover and understand how nature, the universe, or a system works. | Apply knowledge to solve practical problems and create useful solutions. |
| Primary Question   | **"Why does this happen?"**                                          | **"How can we make this work?"**                                         |
| Focus              | Knowledge, theories, principles, and discovery.                      | Design, construction, optimization, and implementation.                  |
| Work Style         | Research, observation, experimentation, and analysis.                | Designing, building, testing, improving, and maintaining.                |
| Output             | Scientific theories, laws, models, discoveries, and research papers. | Products, machines, software, structures, and systems.                   |
| Success Measure    | New understanding and accurate explanations.                         | Reliable, efficient, safe, and useful solutions.                         |
| View of Problems   | Seeks to explain phenomena.                                          | Seeks to solve practical challenges.                                     |
| Use of Mathematics | To model and explain reality.                                        | To design and optimize solutions.                                        |
| Experiments        | Conducted to test hypotheses and discover knowledge.                 | Conducted to verify designs and improve performance.                     |
| Constraints        | Mainly scientific validity and evidence.                             | Cost, time, safety, materials, regulations, and user needs.              |
| Example Question   | Why do stars shine?                                                  | How can we build a better telescope?                                     |
| End Result         | Expands human knowledge.                                             | Expands human capability through technology.                             |

## How Work Is Shared Between Them

| Stage              | Scientist's Role                             | Engineer's Role                                      |
| ------------------ | -------------------------------------------- | ---------------------------------------------------- |
| Observation        | Notices a phenomenon and asks questions.     | Identifies practical needs or problems.              |
| Research           | Studies and discovers underlying principles. | Learns and applies the discovered principles.        |
| Theory Development | Creates models, laws, and explanations.      | Converts theories into designs and specifications.   |
| Prototype          | May demonstrate proof of concept.            | Builds working prototypes and systems.               |
| Testing            | Verifies scientific accuracy.                | Verifies performance, safety, reliability, and cost. |
| Production         | Usually stops after knowledge creation.      | Manufactures, deploys, and maintains the solution.   |
| Improvement        | Discovers new knowledge for future use.      | Continuously improves products and systems.          |

## Example: Airplane

| Step | Scientist                                      | Engineer                               |
| ---- | ---------------------------------------------- | -------------------------------------- |
| 1    | Studies airflow, lift, drag, and aerodynamics. | Uses aerodynamic principles.           |
| 2    | Develops equations and models.                 | Designs wings, engines, and structure. |
| 3    | Tests scientific theories.                     | Builds and tests aircraft prototypes.  |
| 4    | Publishes findings.                            | Produces safe aircraft for passengers. |

## Example: Computer

| Step | Scientist                                  | Engineer                               |
| ---- | ------------------------------------------ | -------------------------------------- |
| 1    | Discovers semiconductor behavior.          | Designs processors and circuits.       |
| 2    | Studies algorithms and computation theory. | Builds operating systems and software. |
| 3    | Creates new knowledge.                     | Creates usable products.               |

## Relationship

| Scientist                           | Engineer                                        |
| ----------------------------------- | ----------------------------------------------- |
| "I discovered a new law of nature." | "I can use that law to build something useful." |

### Simple Flow

```text
Nature
   ↓
Scientist
   ↓ (Knowledge, Laws, Theories)
Engineer
   ↓ (Design, Build, Optimize)
Technology
   ↓
Society Uses It
```

### Real Example

| Person                 | Work Type                                                                      |
| ---------------------- | ------------------------------------------------------------------------------ |
| Isaac Newton           | Discovered laws of motion and gravity.                                         |
| Engineers after Newton | Used those laws to build bridges, rockets, vehicles, satellites, and machines. |

**Scientists discover the rules of the game. Engineers use those rules to build the game.**
